# SIH agriculture PPTs

Index of public Smart India Hackathon decks on farming / agriculture. The decks are hosted by their authors on Scribd and SlideShare. `files/` holds personal-reference PDFs made by screenshotting each publicly viewable slide (Playwright) and joining them; they are image-only, not the original files. The links below are the sources. These are idea-stage submissions, not confirmed winners.
